# 넓은 화면과 소품 품질 점검

2026-11-07. 배경 4종, 소품 아이콘 전체, 시설 4종을 점검했다.

- 배경은 기존 오리지널 원본의 세부 묘사를 유지했다. 화면 너비에 맞춰 늘리지 않고 같은 픽셀 크기로 반복한다. 층별 시작 위치를 달리하고 32px씩 겹쳐 경계의 빈틈을 줄였다.
- 각 층의 알파 윤곽으로 창 영역을 계산한다. 초광폭에서 256개 제한을 넘겨 오른쪽 풍경과 메뉴가 잘리던 문제를 수정했다. 배경은 최대 112개 구간이며 UI 영역을 먼저 확보하고 넘치는 물체 영역은 합쳐 보존한다.
- 이전 소품 14종(울타리, 집, 물그릇, 꽃, 먹이, 곡물, 치료제, 물약, 씨앗, 도시락, 알, 조각, 먹이통, 똥)을 재생성했다. 시설과 같은 나무·청록·크림색 계열로 통일하고 씨앗 봉투와 심어진 새싹, 열린 먹이와 닫힌 주머니를 구분했다.
- 시설 4종은 기존 오리지널 그림을 유지했다. 각 8프레임과 실제 청소·급식·수집·번식에 연결된 동작을 회귀 점검했다. 시설 아이콘은 해당 그림의 첫 프레임을 사용한다.
- 작은 동전·보석·배설 파티클은 기존 애니메이션을 유지한다. 소품 아이콘 교체와 별개이며 모든 원본 효과까지 새로 생성한 것은 아니다.

- 시설·풍경 미리보기의 4개 배경, 작동/휴식, 일시 정지 정상.
