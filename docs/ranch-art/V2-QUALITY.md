# 오리지널 캐릭터 2판 · 손 상호작용

## 최신 적용: 시설 수준의 픽셀 밀도

사용자 피드백에 따라 16색·낮은 해상도 제한을 완화했다. 기존 시설 시트의 빗자루와
우편함은 각각 22×35, 28×35픽셀이며 논리 높이 20·22칸으로 표시한다.
캐릭터는 이전에 논리 1칸당 저장 1픽셀이어서 같은 화면에서 더 거칠게 보였다.

현재는 기존 생성 원화에서 다시 컴파일해 저장 해상도를 가로·세로 2배(총 픽셀 4배),
팔레트를 최대 64색으로 설정했다. 셀 96×96, 발밑 앵커 (48,88), 몸 높이 28~68픽셀이다.
`pixelRatio: 2`를 런타임·미리보기·테두리에 반영해 화면 몸 크기와 상호작용 범위는 유지한다.
이전 저해상도 WebP를 확대하지 않고 원화 PNG에서 직접 다시 만든다.

앞으로 원화 생성 시에도 시설 수준의 세부 묘사를 허용한다. 22~28픽셀짜리 그림이나
10~16색으로 강제하지 않고, 성체 44~68픽셀·아기 28~44픽셀에서 읽히는 눈·귀·발을
기준으로 한다. 아래 16색 및 작은 몸 높이 설명과 `prompts/v2`는 이전 생성 이력이다.

검증: 기존 점검에 화면 몸 높이 유지 검사를 추가해 63개 통과. 실행 중인 학생판에서
밀도 2, 기존 동물 3마리 ID 유지, 런타임 오류 없음 확인.

2026-11-07. 내장 imagegen으로 8종을 각각 새로 제작했다. 프롬프트는
[`prompts/v2/`](prompts/v2/)에, 실제 사용 원화는
`app/web/ranch/originals/*-v2-source.png`에 보관한다. 이전 `*-source.png`는 비교용이다.

## 원본을 다시 살펴본 결과

REA 추출 폴더의 동물 시트를 직접 비교했다. 원본의 접촉 반응 프레임에는 손 그림까지
포함되어 있다(예: chicken_0_1, rabbit_0_1). UI의 cursor/cursor_move 그림은 화살표다.
새 동물 시트에는 손이 없으므로 단순히 프레임 번호만 교체하면 손이 사라진다.
이번에는 손을 별도 캔버스 픽셀 아이콘으로 분리해 모든 종에서 사용한다.
게임 전체의 입력 스크립트를 복원했다는 의미는 아니다.

## 그림과 박자

- 원본의 작고 자연스러운 동물 체형, 구분되는 주둥이와 발, 제한된 색 면을 참고했다.
  새 팔레트와 이름은 유지하되 토끼의 가느다란 귀, 고양이의 긴 꼬리,
  강아지의 늘어진 귀, 여우의 긴 몸통과 큰 꼬리를 더 분명하게 구분했다.
- 성체/아기 각각 18프레임, 총 288프레임. 6가지 기본 동작을 제공한다.
- 몸 높이는 성체 22~34픽셀, 아기 14~22픽셀. 확대 이미지를 그대로 표시하지 않고
  기존 컴파일러의 동일 배율·16색·이진 알파·최근접 축소로 패킹한다.
- 걷기 주기는 종별 0.48~0.8초. 가만히 있을 때는 눈 뜬 자세를 오래 유지한다.
  먹기는 고개 내림 → 씹기 반복 → 들기, 접촉 반응은 1.6초로 구성했다.
- 생성된 고양이는 왼쪽을 보고, 토끼의 잠 프레임도 왼쪽을 본다.
  `flip`/`frameFlip` 메타데이터로 런타임과 미리보기의 방향을 일치시킨다.
  원화 PNG를 다시 그리거나 뒤집어 덮어쓰지 않는다.
- 잠/앉기 전용 진입·종료 원화는 아직 없다. 기존의 6개 기본 상태 구성은 유지한다.

## 상호작용

- 왼쪽 클릭: 1.6초 쓰다듬는 손, 접촉 표정, 하트. 어른의 축적 재화는 한 번만 수령한다.
- 오른쪽 클릭: 상세 패널. 쓰다듬기에 상세 패널이 뜨지 않는다.
- 누르고 끌기: 잡는 손, 들림·흔들림·놓기. 수직 이동만 해도 끌기가 시작된다.
- 클릭 반응은 먹기/걷기보다 우선한다. 손은 투명 창의 영역에도 포함돼 끝이 잘리지 않는다.
- 포커스 이탈 시 들기를 해제한다. 수업 중에는 손·수령 효과 없이 상세 보기만 가능하다.
- `[hidden]`이 `.panel { display:flex }`에 덮여 닫힌 창이 보이던 문제를 수정했다.

## 확인

`python scripts/ranch-art/build-originals.py`

`node scripts/check-ranch.mjs .tmp_ranch/v2-gameplay.png`

미리보기: `app/web/ranch-originals.html`. 테스트는 손 영역, 반응 우선순위, 중복 수령 방지,
세로 끌기, 포커스 이탈, 수업 제한, 기존 돌봄/시설/보관함 및 80개 품질 연결을 확인한다.

결과: 자동 점검 62개 통과. 실행 중인 학생판 목장도 저장 후 다시 로드해
기존 동물 3마리의 ID 유지, 2판 시트 16개 로드, 클릭 시 손 1개 표시,
닫힌 패널 숨김, 런타임 오류 없음까지 확인했다. 이번 변경은 소스와 실행 중인
학생판에 반영했으며 패키지 EXE는 별도로 다시 빌드하지 않았다.
