# 별사이 목장 · 오리지널 시설과 배경

2026-11-07. 내장 imagegen으로 원화 8장을 생성하고 프로젝트 안에 보관했다.
시설은 4종×8프레임, 배경은 4종×3개 층이다. 시설 원본 텍스처를 다시 칠한 것이 아니라
새 디자인과 원화를 생성해 기존 기능에 연결했다.

## 원본 분석

이전에 REA로 추출한 TinyPasture PCK의 `Scene/Level/Buildings` 장면을
`read_godot_scene.py`로 읽었다. [관찰 기록](environment-reference.json)에 프레임과 시간,
노드 이름을 보관한다. GDScript 전체를 복원하거나 실행한 결과는 아니다.

| 원본 시설 | 확인된 구성 | 적용한 동작 |
|---|---|---|
| 자동 청소 | move 1.6초, clean_pre 0.3초, cleaning 0.6초, clean_end 0.2초 | 빗자루가 목표까지 이동→쓸기→귀환 |
| 자동 급식 | open_door 0.8초, spawn_food 0.8초, close_door 0.6초 | 문 열기→장치 회전·먹이 이동→닫기 |
| 자동 수집 | Home·Bee·AnimatedSprite2D·SearchTimer 노드 | 채집통 개폐·반딧불 일꾼 왕복 |
| 번식 | start, waiting 1.6초, creating 6초, finish 1.1초 | 커튼 닫기→진행 중 흔들림→완료 시 열기 |

원본 배경의 구름/산·언덕·앞쪽 풀을 독립된 투명 층으로 겹치는 구성을 참고했다.
새 그림은 달씨앗 풀밭, 아카데미 언덕, 물빛 물가, 이세계 퇴근길이다.

## 원화와 게임용 파일

- 원화: `app/web/ranch/environment/*-source.png` (수정하지 않고 보관)
- [실제 생성 프롬프트](prompts/environment/): 시설 4장·배경 4장, 내장 imagegen 사용
- 시설: 112×112 셀, 4열×2행, 64색, 저장 몸 높이 56~76픽셀.
  `pixelRatio: 2`로 화면 몸 높이를 28~38칸으로 표시한다.
- 배경: 1536×104픽셀 층 3개를 한 WebP에 세로 패킹한다.
  원경/중경/전경의 최대 그림 높이를 96/68/24픽셀로 분리한다.
- `manifest.json`: 원화 SHA-256·자른 위치·출력 규격.
- 생성/패킹: `python scripts/ranch-art/build-environment.py`

기존 시설 아이콘도 상점·상세 패널에서 새 시트의 첫 프레임을 사용한다.
기존 시험용 배경 ID `tp1`~`tp4`는 새 배경으로 호환하며 기존 선택과 소유권을 이어간다.
배경 없음과 시설 레벨·가격·작업 간격은 유지한다.

## 작동과 저장

시설 실제 작업과 연출을 분리했다. 청소·먹이 소모·수집 정산은 기존 함수가 한 번만 처리하고,
시각 효과는 WeakMap에 담아 저장하지 않는다. 재생 프레임은 재화나 동물을 생성하지 않는다.
작업 연출은 실제 대상이 있을 때 시작하고, 오프라인 정산에는 쌓지 않는다.
번식 중 커튼 반복과 완료 시 열림은 `state.breeding` 및 실제 부화 처리에 연결된다.

빗자루의 화면 위치는 작업 목표로 움직이지만 저장된 시설 배치 좌표는 바뀌지 않는다.
움직이는 시설·반딧불·먹이 입자의 영역을 투명 창 영역에 포함해 잘리지 않게 한다.
장식 편집으로 시설을 끌 때는 해당 시설의 작업 연출을 해제한다.

시설 로드, 실제 작업 연동, 이동 영역, 중복 수령 방지, 오프라인 억제,
번식 커튼 반복/완료, 4개 배경과 기존 캐릭터·손 상호작용을 확인했다.

[시설·풍경 미리보기](../../app/web/ranch-environment.html)는 저장자료를 변경하지 않는다.
풍경 4종, 작동/휴식, 일시 정지를 확인했다.

실행 중인 학생판은 로컬 저장 후 새로 로드했다. 기존 동물 ID와 보유 시설 키가 유지됐으며,
새 풀밭과 보유 빗자루, 런타임 오류 없음까지 확인했다. EXE는 이번 작업에서 재빌드하지 않았다.
