# 별사이 목장 오리지널 캐릭터 제작 기준

현재 적용된 2판의 그림·손 연출·박자 변경은 [V2-QUALITY.md](V2-QUALITY.md)를 따른다.
아래 내용은 첫 제작 당시의 분석과 1판 설계 기록이다.

분석·제작일: 2026-11-07. 참고 대상: 이 PC의 TinyPasture Godot 4.3 설치본.
REA로 추출한 리소스와 장면의 프레임 표를 분석하고, 새 캐릭터 원화는 내장 imagegen으로 생성한다.
학습 결과는 아래 제작 규칙과 프롬프트로 남긴다.

## 1. 원본에서 읽은 표현 문법

### 형태와 색

- 옆모습 중심으로 얼굴, 귀, 꼬리만으로 종을 구분한다. 몸은 큰 색 면으로 나누고 작은 털 결은 생략한다.
- 밝은 배·주둥이와 어두운 바깥 윤곽으로 밝거나 어두운 바탕화면에서도 읽히게 한다.
- 눈은 작은 점/짧은 선, 감은 눈은 작은 곡선이다. 표정 변화는 눈뿐 아니라 귀·고개·등의 자세로 만든다.
- 성체와 아기는 단순 확대/축소가 아니다. 아기는 머리 비율이 크고 다리·귀·꼬리가 짧다.
- 원본 배경은 960×50의 독립된 투명 층이다. 구름은 밝고 부드럽게, 산은 청록,
  앞 언덕은 황록으로 구분한다. 배경의 명암 대비를 캐릭터 윤곽보다 낮게 두는 것이 적합하다.

관찰 파일: `Assets/Animals/{rabbit,fox,alpaca,...}_0_{0,1}.png.import`,
`Assets/Deco/Background/bg_01/*`. 원본의 디자인을 그대로 변형하는 대신,
새 캐릭터는 고유한 실루엣·표식·배색을 설계하고 이 작은 화면의 표현 규칙을 사용한다.

### 동작 구조와 박자

REA 추출 후 `read_godot_scene.py`로 읽은 `Sprite:frame` 트랙의 관찰값이다.
아래 숫자는 타임라인 키 수이며, 반복 프레임이 포함돼 고유 그림 수와 같지 않을 수 있다.

| 동작 | 토끼 | 여우 | 알파카 | 제작에 적용할 점 |
|---|---:|---:|---:|---|
| 서 있기 | 4키 / 1.2초 | 6키 / 0.9초 | 4키 / 1.2초 | 움직임보다 멈춤을 길게, 작은 눈깜빡임 |
| 걷기 | 4키 / 0.4초 | 6키 / 0.6초 | 8키 / 0.8초 | 몸 이동과 다리 주기를 분리, 귀·꼬리는 조금 늦게 |
| 먹기 | 9키 / 1.8초 | 12키 / 2.4초 | 12키 / 2.4초 | 고개 내림 → 반복 씹기 → 고개 들기 |
| 접촉 반응 | 8키 / 1.6초 | 8키 / 1.6초 | 8키 / 1.6초 | 즉각 눈/귀 반응 후 부드럽게 돌아오기 |
| 잠 반복 | 6키 / 1.2초 | 9키 / 1.8초 | 6키 / 1.2초 | 눕거나 몸을 말고 호흡만 반복 |
| 잠 시작/종료 | 각 6키 / 0.6초 | 각 6키 / 1.2초 | 각 8키 / 1.6초 | 상태 전환과 반복 구간을 별도로 설계 |

원본은 종에 따라 앉기를 `pre/loop/end`로 나누거나 긴 한 동작으로 둔다.
숫자를 모든 종에 똑같이 복사하기보다, 같은 상태 체계 안에서 생물별 무게감과 박자를 다르게 표현한다.

### 반응 스타일

- 평소에는 작은 숨쉬기와 눈깜빡임으로 조용히 살아 있게 한다.
- 먹이에는 고개와 주둥이가 먼저 움직이고, 쓰다듬기에는 눈·귀·꼬리로 짧게 답한다.
- 잠과 앉기는 몸 높이가 낮아진다. 프레임마다 크기를 맞춰 늘리면 이 차이가 사라지므로 금지한다.
- 상태 말풍선, 품질 테두리, 재화 입자는 몸 그림과 별도로 처리한다.
- 들기/놓기는 현재 목장 엔진의 발밑 앵커·들림·기울기·착지 변형을 사용한다.
  원본의 전체 행동 코드를 복원했다는 의미는 아니며 현재 구현의 반응 규칙이다.

## 2. 새 캐릭터 8종

| 캐릭터 | 식별 특징 | 배색 | 성격·주된 반응 |
|---|---|---|---|
| 달씨앗 토끼 | 비대칭 잎 귀, 금빛 씨앗 이마점, 세 갈래 새싹 꼬리 | 연보라·상아·남보라 | 조심스럽게 귀를 세우고 반응 |
| 해콩 닭 / 병아리 | 꽃잎 볏, 살구 볼, 잎 모양 꼬리 | 버터노랑·살구·크림 | 잠이 많고 쓰다듬으면 작게 들썩임 |
| 물방울 오리 | 물방울 볏, 산호색 주걱 부리, 말린 물갈퀴 꼬리 | 청록·상아·산호 | 고개를 기웃하고 느긋하게 반응 |
| 구름솜 양 | 커다란 구름 양털 덩어리, 금빛 이마 곱슬 | 상아·회청·금빛 | 귀가 낮아졌다가 살짝 올라감 |
| 책갈피 고양이 | 페이지 같은 옆구리 무늬, 고사리 꼬리 | 세이지·크림·짙은 청록 | 꼬리 끝과 눈으로 호기심 표현 |
| 도토리 강아지 | 큰 코코아 귀, 도토리 꼬리, 작은 이끼색 가슴점 | 비스킷·코코아·이끼 | 귀가 늦게 따라오는 경쾌한 반응 |
| 노을꼬리 여우 | 두 갈래 잎 꼬리, 자주색 눈가, 꼬리의 작은 점 셋 | 산호·자주·크림 | 몸보다 큰 꼬리로 수줍게 답함 |
| 별구름 알파카 | 구름 털, 남색 잎 귀, 호박색 이마 마름모 | 청회·상아·호박 | 긴 목을 작게 기울이는 느긋한 반응 |

추가 장식은 캐릭터마다 식별 가능한 한두 부분으로 제한한다. 의상·아이템·반짝이는 입자는
원화 시트에 넣지 않고 게임에서 필요한 경우 따로 그린다.

## 3. 이번 제작용 시트 규격

한 캐릭터당 6열×6행, 36그림. 위 3행은 성체, 아래 3행은 아기다.
한 성장 단계는 다음 18그림을 사용한다. 모든 그림은 오른쪽을 보며 투명 배경이다.

| 위치(성장 단계 안) | 내용 | 재생 |
|---|---|---|
| 0~1 | 서 있기·눈깜빡임 | 0→1→0, 1.8초 |
| 2~5 | 걷기 4포즈 | 0.64초 반복 |
| 6~9 | 고개 내림·먹기·씹기·삼키기 | 1.2초 반복 |
| 10~11 | 기쁜 접촉 반응 | 10→11→10→0, 0.9초 |
| 12~15 | 잠·숨쉬기 | 2.4초 반복 |
| 16~17 | 앉아서 쉬기 | 1.6초 반복 |

이번 1판은 여섯 기본 동작을 제공한다. 원본의 모든 잠/앉기 진입·종료 타임라인을
그림으로 그대로 재현한 것은 아니다. 반복 상태는 확실히 구분하고 전환 시 프레임 시계를 다시 시작한다.

게임용 포장: 48×48 셀, 6열×3행씩 성체/아기 두 파일. 발밑 기준점은 (24,44).
종별 목표 키는 성체 19~34화소, 아기 11~22화소. 16색·이진 알파로 정리하고 최근접 보간만 쓴다.
프레임마다 개별 높이를 맞추지 않고 성장 단계별로 같은 축소 비율을 사용한다.
품질은 같은 새 원화에 다섯 가지 테두리를 적용한다. 기존 참고 게임 색상으로 돌아가지 않도록
모든 품질 항목을 오리지널 시트로 연결한다.

## 4. 재현 가능한 생성·검수 절차

1. 참조 원본은 `view_image`로 보고, 실루엣/색/타임라인 관찰을 정리한다.
2. 캐릭터의 식별 특징, 성격, 성체/아기 차이를 위 표처럼 먼저 고정한다.
3. 내장 imagegen을 사용한다. 실제 생성 프롬프트는 [`prompts/`](prompts/)에 보관한다.
   토끼에는 원본 토끼·여우·배경을 구조/색 참고로, 나머지에는 새 토끼와 배경을 화풍 참고로 제공한다.
4. 생성 원화를 `app/web/ranch/originals/<종>-source.png`에 복사한다. 원화는 덮어 그리지 않는다.
5. `python scripts/ranch-art/build-originals.py`로 프레임을 찾고 스프라이트와 atlas를 만든다.
   생성기가 동일 격자 간격을 보장하지 않으므로 실제 알파의 여섯 행·여섯 열을 검증한다.
   개수가 다르면 추측해서 다음 캐릭터 조각을 섞지 않고 실패시킨다.
6. 원화 SHA-256, 원화 안 프레임 좌표, 출력 파일·키는 `originals/manifest.json`에 남긴다.
7. 작은 실제 크기, 확대, 좌우 방향, 여섯 동작, 아기/성체, 초록/밤 배경에서 확인한다.
8. `node scripts/check-ranch.mjs`로 저장 호환·돌봄·수령·수업 제한·영역 검사를 수행한다.

검수 기준: 36칸 모두 존재, 프레임에 다른 캐릭터가 침범하지 않음, 눈/표식/귀 수 일관,
꼬리와 귀 끝이 잘리지 않음, 잠 자세가 충분히 낮음, 발이 기준선에서 미끄러지지 않음,
아기가 성체보다 작고 비율이 다름, 배경보다 실루엣이 뚜렷함.

생성 이미지의 작은 형태 변화는 자동 검사만으로 판정할 수 없으므로 최종 육안 검수를 병행한다.
제작 경로는 내장 imagegen이며 외부 API/CLI 이미지 생성은 사용하지 않는다.

## 5. 산출물과 이번 검증

- [동작 미리보기](../../app/web/ranch-originals.html): 여섯 동작·성장 단계·방향·배경·일시 정지 선택.
- `app/web/ranch/originals/`: 원화 8장, 게임용 무손실 WebP 16장, atlas와 프레임 출처 manifest.
- 전체 288프레임. 게임용 WebP 합계 45,904 bytes. 각 성장 단계의 18프레임이 모두 존재하며
  눈깜빡임/걷기/먹기/잠/반응/앉기 안의 그림이 각각 서로 다름을 확인했다.
- 게임용 알파는 0/255이며, 생성 원화의 반투명 가장자리 잡음은 게임용 변환에서 제외한다.
- 원본 파일과 기존 종 ID/저장값은 보관하고, 마지막에 읽는 `originals/atlas.js`가
  현재 8종의 외형과 종명만 새 디자인으로 연결한다. 기존 개체의 사용자 지정 이름은 바꾸지 않는다.
- `node scripts/check-ranch.mjs`: 통과. 추가된 창고 동작을 포함한 현재 회귀 검사 전체 통과.
- Playwright: 8개 카드, 여섯 동작, 아기/성체, 밤 배경, 방향 전환·일시 정지 확인.
- 이미지 생성과 소스 반영까지 완료했으며 EXE 재빌드/배포는 수행하지 않았다.
