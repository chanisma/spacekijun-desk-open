# 스페이스기전 교실 (교실판)

교실 PC 에 QR 을 띄운다. 교사가 휴대폰 카메라로 찍으면 스페이스기전 승인 화면(`/classroom/link/<code>`)이 열리고,
**프로필 → 교실 기기 세팅**에 반별로 만들어 둔 세팅을 골라 [이 기기에 펼치기]를 누르면 화면 아래에 그 교사의 **독**이 뜬다.

> 2026-10-13 사용자 결정: «세팅된다» = 프로그램·파일이 저절로 열리는 것이 **아니라**, 쉽게 열 수 있게 독(위젯)에
> 놓이는 것. 드라이브는 파일 하나가 아니라 **드라이브 전체(또는 특정 폴더)를 프로그램 안에서 일반 폴더처럼** 쓰는 것.

## 독

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 김교사 선생님 │ 📁내 드라이브 📁1-3 정보 🌐패들렛 P PowerPoint 🪐자리 배치 │ 38:12 │ 수업 끝 │
│ 1-3 정보 수업 │                                                          │ +10분 │        │
└─────────────────────────────────────────────────────────────────────────┘
```

| 아이콘 | 누르면 |
|---|---|
| 내 드라이브 | 드라이브 탐색기(아래)를 내 드라이브로 연다. 드라이브를 연결했을 때 늘 있다. 남은 시간 10분 안쪽이면 배지 |
| 드라이브 폴더(세팅) | 탐색기를 그 폴더로 연다 |
| 드라이브 파일(세팅) | 받아서 이 PC 의 프로그램으로 연다 — 저장하면 드라이브에 되올린다 |
| 웹사이트 | **이번 수업 전용 Edge 프로필**(빈 임시 폴더)로 연다. 거기서 누가 로그인해도 끝날 때 프로필째 지운다 |
| PC 프로그램 | 이름(허용 목록)으로만 연다 — PowerPoint·Word·Excel·한글·Whiteboard·메모장·그림판·계산기·캡처 도구·화상 키보드. 그 밖은 아래 설정 파일에 등록한 것만 |
| 스페이스기전 화면 | 프로그램 안 창에 교사 세션을 심어 연다. 끝나면 창 저장소를 비우고, 서버가 그 세션을 끊는다 |

독 맨 앞에는 늘 **구글**(G)이 있다 — 아래 «구글 웹 · 로그인 보관».

남은 시간을 누르면 10분 연장(승인부터 최대 4시간). 왼쪽 아래 한 줄에 방금 일어난 일(실패 이유 등)이 뜬다.
독 왼쪽(선생님 이름)을 끌어 옮길 수 있다. 수업 중에는 QR 창이 숨는다.

## 드라이브 탐색기

- 왼쪽: 내 드라이브 · 공유 문서함 · **이 PC 에 복사한 파일** · 이 수업 폴더(세팅) · 공유 드라이브
- 두 번 누르기(또는 Enter): 폴더는 들어가고, 파일은 받아서 연다. 구글 문서·시트·슬라이드·그림은 docx·xlsx·pptx·pdf 로.
- **여러 개 고르기**(2026-10-14): 누르기 = 하나 고르기, Ctrl = 더하기, Shift = 범위, 줄 앞 체크 · 머리줄 체크 = 모두, Ctrl+A · Esc.
  고르면 위 막대의 [새 폴더]·[올리기] 자리가 **[열기]·[컴퓨터로 복사]·✕** 로 바뀐다. 🚨 목록 위에 따로 줄을 끼우면 안 된다 —
  첫 번째 누르기가 그 줄을 띄워 목록이 밀리고, 두 번째 누르기가 **다른 파일**을 연다(2026-10-14 시험에서 실제로 겪음).
- **컴퓨터로 복사**: 고른 파일·폴더(안까지, 한 번에 500개·깊이 10)를 선생님이 고른 이 PC 의 폴더(처음엔 바탕 화면)로 받는다.
  같은 이름 폴더가 있으면 «(2)» 를 붙여 덮지 않는다. 이 수업에서 열어 고친 파일은 드라이브본이 아니라 **교실에서 고친 최신본**을 복사한다.
  복사한 파일은 **수업이 끝나도 지우지 않는다** — 정리 뒤 QR 화면 알림에 «이 PC 에 복사한 파일 N개는 남아 있습니다(위치)»가 뜬다.
  폴더 고르기 창은 그 선생님이 지난번에 고른 폴더에서 열린다.
- **이 PC 에 복사한 파일**(1.5.6, 2026-10-15 사용자 요청 «복사한 파일을 다음 수업에도 쉽게»): 컴퓨터로 복사·이 PC 에 저장 한 것을
  **선생님별로** 기억해(`…\copies\<선생님 해시>.json` — 경로만, 최근 300개) 다음 수업에 왼쪽 «이 PC 에 복사한 파일»에 모아 보여 준다.
  두 번 누르면 파일은 이 PC 의 프로그램으로 열고 폴더는 들어간다. 고르면 [열기]·[위치 열기](Windows 탐색기)·[목록에서 빼기](파일은 그대로)
  ·[지우기](**휴지통으로** — 되살릴 수 있게). **드라이브 연결 없이** 된다 — 연결이 끝난 덮개에도 «이 PC 에 복사한 파일 보기».
  같은 선생님 수업을 열면 «지난 수업에 이 PC 에 복사해 둔 파일 N개…» 알림. 지웠거나 옮긴 것은 목록에서 저절로 빠지고,
  기억한 것 밖(`..`)으로는 열지 못한다(`PcShelf.resolve`). 고쳐도 드라이브에는 올라가지 않는다(이 PC 의 파일).
- **열어 둔 파일**은 목록 줄에도 «열림 · 드라이브와 같음/저장 확인 중/올리는 중/못 올림» 표가 붙는다. 구글 문서를 고친 경우
  원본 줄은 «열림», 새로 생긴 «(교실에서 고침)» 줄은 «교실에서 고친 파일». 아래 칸에서 [다시 열기]·[이 PC 에 저장](고친 지금 내용 그대로 남김).

### 열어 둔 파일은 어디에 있고 언제 지워지나

| | 자리 | 언제 지우나 |
|---|---|---|
| 열어 둔 파일 | `%LOCALAPPDATA%\SpacekijunClassroom\sessions\<수업>\drive\` — 여기서 연다 | 수업이 끝나면(고친 내용을 드라이브에 올린 뒤) |
| 못 올린 파일 | `…\unsent\<선생님별>\` | 같은 선생님이 다음에 드라이브를 연결해 올리면 |
| 컴퓨터로 복사 · 이 PC 에 저장 | 선생님이 고른 폴더 | **지우지 않는다** — 선생님이 남기기로 한 것. «이 PC 에 복사한 파일»의 [지우기]로 휴지통에 |
| 복사한 것 목록 | `…\copies\<선생님별>.json` | 파일이 없어지면 그 줄만 빠진다 |
- **되올리기**: 연 파일의 크기·수정 시각이 바뀌고 2초 그대로면(저장이 끝나면) 드라이브의 **같은 파일에 새 판으로** 올린다.
  구글 문서에서 바꿔 받은 파일은 원본(구글 문서)을 덮을 수 없어서 같은 폴더에 «(교실에서 고침)» 새 파일로 올리고, 그 뒤로는 그 파일을 갱신한다.
  아래 «열어 둔 파일» 줄에 올린 시각·실패 이유가 보인다.
- [올리기](이 PC 의 파일을 지금 폴더로) · [새 폴더] · 새로 고침. 지우기·이름 바꾸기는 없다(교실 화면에서의 실수 방지).
- **연결 시간 1시간**: 10분 남으면 알림 줄, 끝나면 «드라이브 다시 연결» QR 화면이 덮는다. 수업 중인 선생님이 찍으면 1시간 더(다른 선생님은 서버가 거절).
  수업 연결은 그대로라 독·열린 창은 영향이 없다.

## 알림·확인은 따로 뜨는 창 (2026-10-14)

독은 높이가 112 라 그 안에 그린 `confirm()`·긴 알림 글이 잘렸다(사용자 보고, 창 머리에 «127.0.0.1:포트의 메시지»까지 보였다).
그래서 화면 스크립트는 `confirm`·`alert` 를 쓰지 않는다(시험 `test_no_native_dialogs` 가 막는다).

- **알림** — 독 바로 위에 뜨는 작은 창(`classroom-toast.html`, 520×116). 포커스를 가져가지 않고 7초(오류 12초) 뒤 닫힌다.
  화면은 `api.notify(글, 오류?)`, 서버 쪽 알림(드라이브 다시 연결 등)은 `classroom.py` 루프가 같은 글은 한 번만 띄운다.
- **확인** — 화면 가운데 창(`classroom-dialog.html`). 화면은 `await api.ask({title, body, ok, danger})` → 고르면 true/false(최대 5분, Esc = 아니오).
- **구글** — 독의 G 를 누르면 구글 앱 창(`classroom-google.html`): 클래스룸·드라이브·문서·시트·슬라이드·설문지·캘린더·Meet·Gmail·Keep·사이트·YouTube.
  누르면 수업용 Edge 에서 `authuser=선생님 이메일` 로 연다. 아래에 [로그인 창 열기]·[이 PC 로그인 지우기].
  «지우기»는 이 PC 에 지울 로그인이 있을 때만(`google.saved` — 보관을 풀었거나 이번 수업에 수업용 Edge 를 띄웠을 때). 처음 쓰는 기기엔 안 뜬다.
  세팅에 구글 앱을 넣으면(웹 «구글 앱» 탭) 독에 따로 타일이 생긴다(저장은 웹사이트 항목 + `app` 키).

## 항상 켜져 있게 (2026-10-14, 1.3.0)

- QR 창의 **✕ 는 끝내지 않고 내린다**(최소화). 저절로 다시 띄우지는 않는다 — 내려 두면 바탕화면 위젯에 작은 QR 이 있다
  (예전의 «10분 손 놓으면 다시 띄우기»는 2026-10-21 요청으로 뺐다. 쓰던 창 위로 QR 이 갑자기 덮었다).
- 끝내기는 [기기 설정]의 **«프로그램 끝내기»**(확인 창)뿐이다. 수업 중이면 정리부터 한다.
- Windows 가 꺼지거나 로그아웃하는 중(`SM_SHUTTINGDOWN`)이면 ✕ 를 막지 않는다 — 막으면 «이 앱이 종료를 막고 있습니다»가 뜬다.
- 갑자기 죽으면(처리하지 못한 오류) 실행 파일이 **스스로 다시 켠다**(`--autostart --wait-pid <옛 pid>` — 옛것이 한 번에 하나 잠금을 놓기를 기다림).
  1분 안에 또 죽으면 되풀이하지 않고 오류 창을 띄운다(`last-crash.txt`). 작업 관리자로 끈 것은 다시 켜지 않는다(다음 Windows 시작 때 자동 실행).
- QR 화면 오른쪽 아래에 **세팅 만들기 QR**(스페이스기전 `/classroom`, 메뉴 [도구] → 교실 기기) — 세팅이 없는 선생님이 휴대폰으로 바로 간다.

## 내려 두면 작은 위젯 (2026-10-14, 1.3.1)

- QR 창을 내리면(✕ · 작업 표시줄 · 최소화) **바탕화면 오른쪽 아래에 작은 위젯**(`web/classroom-mini.*`, 340×124)이 뜬다 —
  작은 QR(그대로 찍어 연결된다) · 기기 이름 · 남은 시간 · [QR 크게 보기].
- 항상 위가 아니다(다른 창에 깔리는 바탕화면 위젯). 도구 창 스타일이라 작업 표시줄·Alt+Tab 에는 없다(QR 창이 작업 표시줄에 있다).
- QR 창이 다시 뜨면(복원 · 최대화 · 위젯의 [QR 크게 보기] · 수업 시작으로 독이 뜸) 위젯은 닫힌다. 수업 중(독)에는 뜨지 않는다.
- **켤 때도 내려 둔 채**(1.5.3 요청) — QR 창은 최소화로 시작하고 위젯만 뜬다(`minimized=True` → `Windows.lower()`).
  작업 표시줄로 열면 최대화된 QR 로(최소화로 시작한 창은 «보통» 크기로 돌아오므로 `restored` 에서 최대화).
- 🚨 프로그램을 끝낼 때(«프로그램 끝내기» · 업데이트 · Windows 종료) 위젯도 닫아야 한다 — 창이 남으면 프로그램이 안 끝난다.

## 구글 수업 도구 — 로그인 없이 (2026-10-14, Windows 1.4.0 · 전자칠판 1.1.0)

드라이브는 QR 토큰으로 바로 되는데 클래스룸·슬라이드·폼은 구글 웹 로그인이 필요했다(사용자 보고). 구글 웹 로그인(쿠키)은 OAuth 토큰으로
만들 수 없어(구글 자체 Chrome 만 된다), 기기가 **구글 API 를 직접 불러 프로그램 안 화면**으로 보여 준다(드라이브와 같은 방식).

- 화면: `web/gtools.js`·`gtools.css` — Windows(`classroom-gtools.html`, 큰 창)와 전자칠판(board.html 안)이 같은 파일을 쓴다(안드로이드는 빌드 때 복사).
- **원래 구글 화면과 최대한 같게**(같은 날 요청, Windows 1.4.1 · 전자칠판 1.1.1): 클래스룸은 수업 카드(색 띠·선생님 사진) → 스트림(배너 ·
  수업 코드 · 예정된 과제 · «수업에 공지하기» · 작성자 사진·이름 · 첨부 카드) · 수업(주제별, 제출함/할당됨) · 사용자(교사·학생) 탭,
  슬라이드는 «최근 프레젠테이션» 격자 → 편집 화면처럼(왼쪽 필름 띠 · [슬라이드쇼]) → 검은 슬라이드쇼(왼쪽 아래 조작 막대),
  설문지는 보라 띠 · [질문 | 응답 n] 탭 · [보내기](QR) · 원형/막대 차트. 아래 줄(수업 화면 · 도구 · 뒤로)만 칠판 손닿음 때문에 우리 것.
  이를 위해 승인 범위에 rosters.readonly · profile.photos · topics.readonly · courseworkmaterials.readonly 를 더했다(교사마다 구글 허용 창 한 번 더).
  권한이 없는 부분만 비우고 «다음 승인 때 허용하면 보입니다»를 띄운다.
- 🚨 **클래스룸 목록 응답의 필드 이름**: 자료는 `courseWorkMaterial`, 주제는 `topic`(단수) — 과제 `courseWork`·공지 `announcements`·
  학생 `students` 와 다르다. 복수로 읽어 자료·주제가 늘 비어 보였다(1.4.4 · 1.1.3 에서 고침, 두 이름을 다 본다).

  못 불러온 부분은 감추지 않고 «수업 자료을(를) 불러오지 못했습니다: 이유»처럼 알린다. 새 판 확인은 30분마다(데스크는 6시간 그대로).
  - **클래스룸**: 내가 가르치는 수업 → 공지(보기·**올리기**, 확인 창) · 과제(기한·제출 현황 n/m) · 수업 코드 크게 + 참여 QR.

  - **설문지**: 응답 QR(학생 휴대폰) · 응답 수 · 질문별 집계(선택형 막대, 글 답 최근 8개), 15초마다 새로.

## 휴대폰으로 구글 비밀번호 입력 (2026-10-14, Windows 1.5.0 · 전자칠판 1.2.0)

칠판에서 구글 비밀번호를 치면 학생들에게 보일 수 있다(사용자 보고). 사용자 결정(B): 휴대폰에서 입력해 이 기기로만 보낸다.
- 흐름: 독의 «구글» 창 [휴대폰으로 로그인](Windows) · 앱 안 브라우저가 구글 로그인 화면일 때 [📱 휴대폰으로 입력](칠판) → 일회용 키(P-256)를
  만들어 서버에 맡기고 QR(`/classroom/type/<표>#k=<공개키>`) → 선생님 휴대폰에서 비밀번호 → 휴대폰이 봉한 것을 받아 풀어 구글 로그인 칸에 넣고 [다음].
  이메일·계정 고르기 화면이면 먼저 그 단계를 넘긴다. 2단계 인증은 구글 알림대로.
- 암호: ECDH → HKDF-SHA256(salt=표, info=`spacekijun-classroom-type-v1`) → AES-256-GCM. 서버는 암호문만, 받으면 지움, 3분 만료.
  비밀번호는 이 기기에 저장하지 않는다. 웹(`typeCrypto.ts`)이 만든 같은 표본을 Windows(`core/classroom_type.py`)·칠판(`TypeRelay.kt`) 시험이 푼다.
- Windows(1.5.1~): **UI Automation** 으로 넣는다(`core/classroom_type.py EdgeUia` — pywebview 가 쓰는 pythonnet 으로 .NET UIAutomationClient).
  수업용 Edge 브라우저 프로세스(`Session.edge_pids()` — 이 수업 프로필 `--user-data-dir`, `--type=` 없는 msedge.exe) 창 안에서,
  **주소가 `https://accounts.google.com/` 인 문서에만** 값을 넣고(`ValuePattern.SetValue`) [다음](이름 `다음|Next` 이 딱 하나일 때만)을 누른다.
  키 입력·클립보드는 쓰지 않는다. UIA 는 Edge 의 **앞에 띄운 탭**만 보인다.
  - 🚨 **디버깅 포트(`--remote-debugging-port`)로 Edge 를 띄우면 구글이 로그인을 막는다** — «로그인할 수 없음 · 브라우저 또는 앱이
    안전하지 않을 수 있습니다». 1.5.0 이 CDP 로 넣으려고 포트를 열었다가 사람이 직접 눌러도 막혔다(2026-10-14 실제 확인). 다시 열지 말 것(시험이 지킨다).
  - 구글 로그인 화면(2026-10-14): 이메일 칸은 `type=text`(`id=identifierId`, `name=identifier`) — `type=email` 이 아니다. 비밀번호 칸 앞에
    숨은 `hiddenPassword` 가 있다 → 보이는 칸만. 1.5.0 이 «구글 로그인 화면을 찾지 못했습니다»로 실패한 까닭. UIA 의 AutomationId = HTML id.
  - [다음] 후보가 0·2개 이상이면 비밀번호만 넣고 «[다음]을 눌러 주세요». 이메일 화면에서 안 넘어가면(계정 없음 등) 그렇게 알린다.
- 칠판: 앱 안 브라우저(WebView)에 `evaluateJavascript` 로 넣는다(`TypeRelay.fillScript` — 위와 같은 칸 규칙).
- 진짜 서버로 끝까지 확인함: 보내기 → 서버에는 epk·iv·ct 만 → 기기가 풀어 같은 비밀번호 → 두 번째는 만료 → 다른 기기는 거절(not_active).

## 화면 배율 · 터치 (2026-10-14, 1.3.2)

- **창 자리는 논리 픽셀로**(`classroom.py work_area()`) — pywebview 는 `webview.screens` 를 물리 픽셀로 주고 `create_window`
  의 x·y·크기는 논리 픽셀로 받아 배율을 곱한다. 화면 크기를 그대로 쓰면 배율 150% PC 에서 독·작은 위젯·알림 창이 가운데가
  아니라 오른쪽 아래(화면 밖)로 밀렸다. 작업 영역(작업 표시줄 뺀 곳, `SPI_GETWORKAREA`)을 시스템 DPI 로 나눠 쓴다.

  켰을 때 `<dialog>`(showModal) 안 단추가 터치로 눌리지 않았다. 단추 높이 44px, 바깥을 누르거나 Esc 로 닫는다.

## Windows 자동 실행 (2026-10-14)

교실 PC 는 켜면 곧바로 QR 을 찍을 수 있어야 한다(1.5.3 부터 QR 창은 내린 채, 오른쪽 아래 위젯으로) — **실행 파일로 처음 켤 때 저절로 자동 실행을 등록한다**(`core/classroom_startup.py`,
`HKCU\…\Run\SpacekijunClassroom` = `"…\SpacekijunClassroom.exe" --autostart`). QR 화면 [기기 설정]의 «Windows 를 켜면 자동으로 실행»으로
끄면 `classroom.json` 의 `autostart: false` 로 기억해 다시 켜지 않는다. 실행 파일을 옮기면 켤 때 새 자리로 고친다.
학교가 PC 전체(HKLM Run, 예: Intune)에 걸어 두었으면 그것을 따르고 스위치는 켜진 채 잠근다. 데스크(`core/startup.py`)와 이름이 달라 서로 지우지 않는다.
자동 실행이 겹쳐 두 번 켜지면 «이미 켜져 있습니다» 창 없이 조용히 끝낸다.

## 구글 웹 · 로그인 보관 (A+, 2026-10-14)

구글은 다른 기기로 웹 로그인을 넘기는 것을 막아, QR 승인으로 받은 토큰(드라이브 API 용)으로는 클래스룸·슬라이드·폼 웹에
로그인시킬 수 없다. 그래서 독의 **구글**을 누르면 수업용 Edge 에서 구글 로그인 화면이 **이메일을 채운 채** 열리고,
선생님은 휴대폰 알림의 «예»(또는 비밀번호)로 로그인한다. 세팅의 구글 사이트(클래스룸·폼 주소 등)도 같은 Edge 에서 열려 함께 로그인된다.

**보관(A+)**: 승인 화면의 «이 교실 PC 에 구글 로그인 보관»(기본 켬)이면, 수업이 끝날 때 그 Edge 프로필을 묶어
AES-256-GCM 으로 잠가 `%LOCALAPPDATA%\SpacekijunClassroom\profiles\<ref>.bin` 에 둔다(`core/classroom_vault.py`).
열쇠는 이 PC 에 없고 서버(`classroom_profile_key`, 선생님×PC 하나)가 쥐고 있다가 **같은 선생님이 이 PC 에서 QR 로 승인할 때만** 넘긴다
→ 다음 수업엔 G 에 ✓ 가 붙고 로그인된 채 열린다.

- 보관하는 것: 쿠키·저장소 등 로그인에 필요한 것. 캐시·모델·업데이트 조각은 뺀다(시험에서 약 1.3MB).
- 수업이 끝날 때 Edge 를 **먼저 점잖게 닫는다**(쿠키를 디스크에 쓰게) → 8초 뒤 남은 것만 강제로 → 잠가 보관 → 풀린 프로필 삭제.
  - 🚨 점잖게 닫기는 `taskkill /PID <pid>` — **`/T` 를 붙이지 않는다.** `/T` 는 자식 프로세스가 있으면 «/F 로 강제 종료해야 합니다»로
    거절된다(Edge 는 늘 자식이 있다). 1.5.3 까지 그래서 Edge 가 **늘 8초 뒤 강제로 죽었고**, 디스크에 아직 안 쓴 쿠키(Chromium 은 약 30초마다
    쓴다 — 구글은 쓰는 내내 로그인 쿠키를 바꾼다)를 잃어 «지우기는 뜨는데 로그인은 안 돼 있음»이 됐다(2026-10-14 사용자 보고).
    실제 Edge 재현: 고치기 전 11.1초·직전 쿠키 잃음 → 고친 뒤 1.8초·직전 쿠키까지 남음. 강제는 자식까지(`/T /F`).
- 보관을 풀었으면 독의 «구글»은 **곧장 `www.google.com`** — 로그인 화면(`ServiceLogin`)을 열면 로그인돼 있어도 로그인 화면처럼 보인다.
  [휴대폰으로 로그인]만 로그인 화면을 연다(`open_google(login=True)`).
- 지우기(1.5.5~): 구글 창 «이 PC 로그인 지우기» → Edge·지금 프로필·보관 파일 삭제. **서버 열쇠와 보관 모드는 그대로** —
  지운 뒤 다시 로그인하면 수업이 끝날 때 새로 보관한다. 🚨 1.5.4 까지는 «서버 열쇠부터 지우고 이번 수업도 남기지 않음»이라,
  «지우기 → 휴대폰으로 다시 로그인 → 수업 끝» 한 로그인이 사라졌다(2026-10-14 사용자 보고 — 서버 로그에서 승인 13초 뒤
  `classroom_profile_forget` 확인, 다음 승인 때 새 열쇠). 보관 자체를 끄려면 승인 화면에서 보관을 끄고 승인(서버가 열쇠를 지운다).
- **로그인 상태 표시**(1.5.5, 사용자 요청): 구글 창 아래 한 줄.
  - 열 때마다 수업용 Edge 앞 탭이 구글 페이지면 접근성(UIA)으로 계정 단추를 읽는다 — «Google 계정: 이름 (이메일)» → «✓ 로그인됨 · 이메일»,
    오른쪽 위 [로그인] 단추 → «로그인되어 있지 않습니다»(`classroom_type.signed_in_email`). 구글 페이지가 앞에 없으면 아래 상태로.
  - 수업 시작에 풀어 넣은 보관본에 구글 로그인 쿠키(`.google.com` 의 SID · __Secure-1PSID · __Secure-3PSID, 만료 전)가 있나
    (`classroom_vault.google_login_in` — 쿠키 DB 의 이름·만료만, 값은 안 읽음) → «불러왔습니다» / «보관본에 로그인이 없었습니다».
  - 🚨 Edge 가 떠 있는 동안 쿠키 DB 는 독점 잠금이라 못 읽는다(실제 확인) — 띄우기 전·닫은 뒤에만 읽는다.
  - 수업 끝: Edge 를 닫은 뒤 다시 보고 QR 화면 알림에 «구글 로그인을 이 PC 에 암호화해 보관했습니다» / «로그인되지 않은 채 끝나
    보관할 로그인이 없었습니다»(`Session.end_login`).
- 열쇠가 맞지 않으면(지웠다·새로 만들었다) 보관 파일을 지우고 빈 프로필로 시작한다. 60일 넘게 안 쓴 보관은 켤 때 지운다.
- Edge 는 쿠키를 이 Windows 사용자의 DPAPI 로 한 번 더 잠근다 — 다른 PC·다른 사용자로 옮긴 보관은 풀려도 로그인되지 않는다.
  같은 PC 에서 다른 폴더로 푼 프로필의 쿠키는 그대로 읽힌다(2026-10-14 실제 Edge 로 확인).
- 다시 로그인해야 하는 때: 학교 Workspace 의 로그인 유지 기간이 지남 · 비밀번호 변경 · 다른 PC · 지우기.
- ⚠️ 수업 중에는 프로필이 풀려 있다. 프로그램이 갑자기 꺼지면 다음에 켤 때 남은 Edge 를 닫고 풀린 프로필을 지운다(보관본은 지난 수업 것).

## 수업 끝

정해 둔 시간이 지남 · 독의 [수업 끝] · 휴대폰의 «여기서 수업 끝내기»(20초 안에 알아챔). «컴퓨터로 복사»·«이 PC 에 저장» 한 파일은
건드리지 않는다. 순서:

1. 스페이스기전 창을 비우고 닫는다. 임시 Edge 는 강제로 닫는다.
2. 우리가 띄운 프로그램과 받은 파일을 연 프로그램은 **점잖게** 닫는다 — 고친 문서가 있으면 프로그램이 저장할지 묻는다. 최대 60초 기다린다.
3. 저장된 드라이브 파일을 마지막으로 올린다.
4. 그래도 못 올린 파일(토큰이 끝났다 등)은 이 PC 의 `unsent\<선생님별>` 에 남겨 두고, **같은 선생님이 다음에 드라이브를 연결하면** 드라이브의
   «교실에서 올리지 못한 파일» 폴더로 올린 뒤 지운다. ⚠️ 그 사이 이 PC 에 파일이 남는다(데이터를 잃지 않으려는 선택).
5. 수업 폴더(받은 파일·임시 Edge 프로필)를 지우고 QR 로 돌아간다. 프로그램이 갑자기 꺼졌으면 다음에 켤 때 남은 프로세스를 닫고 지운다.

창(QR 창)을 닫아도 같은 정리를 한다.

## 실행 · 빌드

```powershell
스페이스기전-교실.bat                       # python app/classroom.py
python -m PyInstaller --noconfirm --clean SpacekijunClassroom.spec   # dist/SpacekijunClassroom.exe (약 20MB)
cd app; python -m unittest test_classroom   # 가짜 서버·드라이브·실행으로 흐름 시험
```

Microsoft Edge 와 WebView2 Runtime 이 필요하다. 데스크(`desktop.py`)를 쓰지 않는 따로 된 창이고, 저장 폴더도 따로다
(`%LOCALAPPDATA%\SpacekijunClassroom`). `core/edition.py` 의 판(교사·학생)과도 무관하다.

| 파일 | 하는 일 |
|---|---|
| `classroom.py` | 입구 · 창 셋(QR · 독 · 드라이브 탐색기) · 화면이 부르는 Api |
| `core/classroom_link.py` | 서버(DB RPC `classroom_device_call` — 2026-11-10 까지 Edge Function `classroom-link`) · 기기 키 · QR 그림 |
| `core/classroom_controller.py` | 흐름 — QR → 수업 → 정리, 드라이브 다시 연결 QR |
| `core/classroom_setup.py` | 독 항목 열기(프로그램 허용 목록 · 임시 Edge) · 정리 |
| `core/classroom_drive.py` | 드라이브 API · 되올리기 · 못 올린 파일 |
| `web/classroom*.html/css/js` | QR 창 · 독(`-dock`) · 탐색기(`-drive`). 독 아이콘 색은 데스크와 같은 `dock-tones.css` |

## 이 기기 설정

QR 화면 오른쪽 위 [기기 설정]에서 **기기 이름**을 바꾼다(기본 = 컴퓨터 이름). 교사 휴대폰의 승인 화면에 이 이름이 뜨므로
`2-3 교실` 처럼 알아볼 수 있게. 추가 프로그램은 `%LOCALAPPDATA%\SpacekijunClassroom\classroom.json` 에 등록한다:

```json
{"device_name": "2-3 교실",
 "programs": {"geogebra": {"label": "지오지브라", "path": "C:\\Program Files\\GeoGebra\\GeoGebra.exe"}}}
```

교사는 세팅 창에서 «기기에 등록한 다른 프로그램…»을 골라 `geogebra` 를 입력한다. 서버에는 이름만 가고 경로는 이 PC 만 안다.

## 보안 메모

- 이 PC 는 아무 계정으로도 로그인하지 않는다. 처음 켤 때 만든 기기 키(`device.key`, DPAPI — 이 PC·이 Windows 사용자만 풂)로만
  서버에 자기를 증명한다. 서버는 키의 sha256 만 둔다. 같은 키로 두 개가 돌면 서로의 QR 을 접어 3초마다 QR 이 바뀐다
  (2026-10-13 시험 중 옛 exe 가 남아 실제로 겪음 — 한 PC 에서는 중복 실행 막기가, 다른 PC 로 복사한 키는 DPAPI 가 막는다).
- 승인 때 받는 토큰(구글 · 스페이스기전 세션)은 **메모리에만** 둔다. 디스크에 쓰지 않는다.
- 🚨 **드라이브 토큰은 전체 드라이브 읽기·쓰기(`drive`)다.** 구글의 «제한된 범위»라, 학교 구글 클라우드의 OAuth 동의 화면
  (클라이언트 `491214877392-…`)이 **내부(Internal)** 여야 학교 계정이 검수 없이 허용한다. 외부면 미확인 앱 경고가 뜨거나 막힌다.
- 서버 · 휴대폰 쪽 설계와 스키마: SPACEKIJUN `docs/features/classroom-link.md`.
- 안드로이드 전자칠판판: `android/` (2026-10-14, 1.0.0) — 같은 서버 계약(`platform: "android"`), 상세 `android/README.md`.
