연결 및 설정

업무 계정과 쪽지 알림을 내 업무에 맞게 설정하세요.

Windows 자동 실행

PC에 로그인하면 데스크를 준비합니다.

현재 Windows 계정에만 적용됩니다. SPACEKIJUN 계정이 연결되어 있으면 자동 감시를 시작합니다. 쿨메신저는 별도로 실행·로그인되어 있어야 합니다.
파일을 옮기거나 새 버전으로 교체한 뒤에는 그 실행 파일을 한 번 실행해 주세요.

프로그램 업데이트

새 판은 저절로 받아 두었다가 쉬는 틈에 바꿉니다. 지금 바로 확인하고 바꿀 수도 있습니다.

확인 중

«지금 업데이트»를 누르면 데스크가 잠깐 꺼졌다가 새 판으로 다시 켜집니다. 열어 둔 업무시스템 창은 닫히니 저장을 먼저 마쳐 주세요. 트레이 아이콘 메뉴에서도 할 수 있습니다.

독 아이콘

바탕화면 독에 보일 아이콘을 고르세요. 바꾸면 독에 바로 반영됩니다.

확인 중

아이콘을 누르면 켜고 끕니다. 적어도 하나는 남겨야 합니다. 숨긴 아이콘의 기능은 데스크 창에서 그대로 쓸 수 있습니다.

인증서 자동 로그인

아이디와 인증서 암호는 이 PC에 암호화하여 보관합니다.

미등록

나이스·업무포털·에듀파인에서 입력한 이름이 포함된 인증서를 선택합니다. 일치하는 인증서가 여러 개면 이름 전체나 구분 문구를 입력해 주세요. 이름을 비우면 인증서가 하나일 때만 자동 선택합니다.
저장된 암호는 표시하지 않으며, 암호 칸을 비우고 저장하면 기존 암호를 유지합니다.

리로스쿨 자동 로그인

리로스쿨은 인증서를 쓰지 않습니다. 아이디와 비밀번호를 이 PC에 암호화하여 보관합니다.

미등록

저장하면 홈의 리로스쿨 버튼이 자동 로그인으로 바뀝니다. 저장 전에는 예전처럼 기본 브라우저로 열립니다.
저장된 비밀번호는 표시하지 않으며, 비밀번호 칸을 비우고 저장하면 기존 비밀번호를 유지합니다.

전북 AIEP 자동 로그인

AI 교수학습 플랫폼 아이디와 비밀번호를 이 PC에 암호화하여 보관합니다.

미등록

아이디는 @ai.jbedu.kr 앞부분만 넣으면 됩니다. 전체 주소를 넣어도 꼬리를 떼고 씁니다.
저장하면 홈의 전북 AIEP 버튼이 자동 로그인으로 바뀝니다. 저장 전에는 예전처럼 기본 브라우저로 열립니다.
저장된 비밀번호는 표시하지 않으며, 비밀번호 칸을 비우고 저장하면 기존 비밀번호를 유지합니다.

연수포털 자동 로그인

전북교육연수포털(jbstudy.kr) 아이디와 비밀번호를 이 PC에 암호화하여 보관합니다.

미등록

저장하면 홈의 연수포털 버튼이 자동 로그인으로 바뀝니다. 로그인까지만 대신하고, 연수 수강은 직접 하셔야 합니다.
저장된 비밀번호는 표시하지 않으며, 비밀번호 칸을 비우고 저장하면 기존 비밀번호를 유지합니다.

쪽지 알림 · 답장 연동

새 쪽지는 스페이스기전 알림으로, 답장은 쿨메신저로 연결합니다.

계정 연결 대기

계정을 연결하면 앱 실행 중 항상 감시합니다. 창을 닫아도 트레이에서 계속 동작합니다.

쿨메신저 연동 알림은 생성 후 한 달이 지나면 서버에서 자동 삭제됩니다.

쪽지 계정

어느 계정의 쪽지함을 볼지 정합니다.

확인 중

쿨메신저는 로그인했던 계정마다 쪽지 파일을 이 PC에 따로 남깁니다. 자동은 가장 최근에 사용한 계정을 읽습니다. 다른 계정의 옛 쪽지가 보이면 여기서 직접 골라 주세요.

계정 연결 상태 확인 중

쿨메신저 연결
