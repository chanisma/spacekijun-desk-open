# 별사이 오리지널 캐릭터

2026-11-07, 내장 imagegen으로 만든 새 디자인 8종.
달씨앗 토끼 · 해콩 닭/병아리 · 물방울 오리 · 구름솜 양 · 책갈피 고양이 ·
도토리 강아지 · 노을꼬리 여우 · 별구름 알파카.

- `*-v2-source.png`: 현재 적용 원화. 6열×6행, 성체 18그림 + 아기 18그림.
- `*-source.png`(v2 제외): 이전 1판 원화. 비교용으로 보존한다.
- `*_adult.webp`, `*_baby.webp`: 각각 96×96 셀 18개, 6열×3행. 저장 몸 높이는 28~68픽셀, 화면 몸 크기는 기존 14~34칸을 유지한다(`pixelRatio: 2`). 팔레트는 64색이다.
- `atlas.js`: 클립·키프레임 시간·방향·발밑 앵커·품질별 연결·종명.
- `manifest.json`: 원화 해시·잘라낸 위치·출력 정보.

재생성: 저장소 루트에서 `python scripts/ranch-art/build-originals.py`.
원화는 이 명령으로 생성하지 않는다. 2판 생성 프롬프트는 `docs/ranch-art/prompts/v2/`에 있다.
