# 리로스쿨 알림 문자 문체 프로필

- 작성일: YYYY-MM-DD
- 마지막 수정: YYYY-MM-DD
- 작성 방법: 첫 사용 인터뷰 (SKILL.md '처음 쓸 때')

> 에이전트가 문자 초안을 쓰기 전에 이 파일을 읽는다.
> **학생·학부모 이름, 전화번호, 실제로 보낸 문자 본문은 적지 않는다.** 규칙과 일반화한 예시 문장만 적는다.
> 문자는 **90byte(한글 약 45자) 이하면 단문(1건 차감), 넘으면 장문(3건 차감)** 이다. 길이 규칙도 아래에 정한다.

## 1. 말투
- 존댓말 수준: (예: 합쇼체 "~드립니다" / 해요체 "~해요" / 섞음)
- 이모티콘·기호: (예: 사용 안 함 / `^^` 만 허용)
- 문장 길이·어미: (예: 짧게 끊고 "~바랍니다" 로 마무리)

## 2. 시작과 맺음 · 서명
- 시작 문구: (예: `[학교명]` 말머리 / `학부모님 안녕하세요.`)
- 맺음 문구: (예: `감사합니다.`)
- 서명: (예: `3학년 8반 담임 ○○○` — **이름은 규칙으로만 적고 실제 이름은 사용자가 말할 때 넣는다**)
- 수신자 호칭: (예: `학부모님` / `{성명} 학생` — 치환 변수는 `{성명}` 만 쓸 수 있다)

## 3. 구조 · 길이
- 기본 순서: (예: 말머리 → 요지 한 줄 → 일시·장소 → 요청 → 맺음)
- 길이: (예: 가능하면 단문(90byte) / 필요하면 장문 허용)
- 날짜·시간 표기: (예: `10/28(화) 15:00`)
- 링크: (예: 짧은 링크만 / 쓰지 않음)

## 4. 수신자별 차이
- 학부모: (예: 높임말, 학교 말머리)
- 학생: (예: 해요체, 짧게)
- 교사: (예: 간단하게)

## 5. 하지 않을 것
- (예: 성적·건강·상담 내용 등 **개인 민감정보를 문자 본문에 쓰지 않는다**, 느낌표 여러 개, 광고성 문구)
- 문자 본문에는 다른 학생의 이름을 넣지 않는다 (`{성명}` 치환만).

## 6. 발송 전 확인 규칙
- 기본: **모든 문자는 미리보기(받는 사람·건수·본문)를 보여 주고 승인을 받은 뒤에만 발송한다.**
- 예외: (사용자가 직접 허용한 것만 적는다. 없으면 비워 둔다)

## 7. 예시 (이름·정보 없이 일반화한 문장만)
```
[학교명] 학부모님 안녕하세요. (요지 한 줄) (일시·장소) 감사합니다. - 3학년 ○반 담임
```

## 8. 교정 이력 (사용자가 초안을 고쳐 달라고 할 때마다 한 줄 추가)
- YYYY-MM-DD — (무엇을 어떻게 바꾸라고 했는지 → 위 규칙에 반영했는지)
