# 업무 자료 정리 (스페이스기전 데스크 업무 스킬)

업무(명단 작성·품의·기안·나이스 입력 …)를 끝낸 뒤, **그 업무에 쓴 파일만** 업무별 폴더로 모은다.
다운로드 폴더에 원자료·작성본이 쌓이지 않게 하고, 나중에 «그 업무 때 쓴 파일»을 한곳에서 찾게 하는 것이 목적이다.

## 지킬 것
1. **옮기기 전에 목록을 보여 주고 승인을 받는다.** 승인 없이 옮기거나 지우지 않는다.
2. **이번 업무에 실제로 쓴 파일만.** 이름이 비슷해도 다른 날짜·다른 업무 파일(예: 다른 회차 제출내역)은 넣지 않는다.
   애매하면 넣지 말고 묻는다.
3. **옮긴다(복사 아님).** 같은 이름이 이미 있으면 덮어쓰지 않고 건너뛰어 알린다.
4. 옮긴 것은 모두 `업무\정리 기록.csv` 에 남긴다 — 되돌리기는 이 기록으로 한다.
5. **지우기는 따로 승인.** 에이전트가 작업 중 만든 임시 파일(화면 캡처·중간 결과)에 학생·교직원 정보가 있으면
   «보관 / 지우기»를 사용자가 고르게 한다. 사용자의 원본 파일은 지우지 않는다.
6. 파일 내용은 정리에 필요한 만큼만 본다. 이름·내용의 개인정보를 결과 보고나 다른 곳에 옮겨 적지 않는다.
7. **원본은 서버에 올리지 않는다.** 서버에는 개인정보를 뺀 업무 요약만, 검사·승인 뒤에 (아래 5).

## 순서

### 1. 후보 모으기
대화에서 이 업무에 쓴 파일을 먼저 적는다 — 사용자가 준 경로, 읽은 원자료, 만든 결과물, 첨부로 보낸 파일.
빠진 것이 없는지 최근 파일도 훑는다(읽기만):
```powershell
& "<스킬 폴더>\scripts\candidates.ps1" -Since "2026-10-30 08:00"     # 또는 -Hours 6
# 다운로드·바탕화면·자동화 업무 폴더(스킬·업무 폴더 제외)에서 그 뒤에 바뀐 파일
```
목록에 나왔다고 넣지 않는다 — 이 업무와 관련 있는 것만 후보로 올린다.

### 2. 목록 보여 주기 → 고르게 하기
| 파일 | 지금 위치 | 제안 |
|---|---|---|
| 8-9월 동아리 입력.pdf | 다운로드 | 보관(옮김) |
| 01_화면캡처.png | 임시 폴더 | 지우기 (학생 정보) |

- 제안은 «보관(옮김) / 지우기(임시 파일만) / 그대로» 셋 중 하나.
- 폴더 이름도 같이 보여 준다: `업무\<날짜>_<업무명>` — 날짜는 **운영일(행사·마감일)이 있으면 그 날, 없으면 오늘**(YYYY-MM-DD), 업무명은 짧게(예: `2026-11-07_AI교과융합 특강`).

### 3. 옮기기 (승인 뒤)
```powershell
& "<스킬 폴더>\scripts\move.ps1" -Task "동아리 누가기록 입력(8~9월)" -Date 2026-10-30 -Files "C:\Users\…\Downloads\a.pdf","…" -WhatIf   # 미리보기
& "<스킬 폴더>\scripts\move.ps1" -Task "동아리 누가기록 입력(8~9월)" -Date 2026-10-30 -Files "…"                                    # 실제로
```
- 작업 폴더(`자동화 업무`)는 스킬이 설치된 위치에서 찾는다(못 찾으면 `%USERPROFILE%\자동화 업무`). `-Root` 로 바꿀 수 있다.
- 이미 같은 업무 폴더가 있으면 그 안에 더한다. 같은 이름 파일은 건너뛰고 «건너뜀»으로 알린다.
- 열려 있는 파일은 옮기기가 실패한다 → 닫고 다시 하라고 알린다.

### 4. 지우기 (따로 승인한 임시 파일만)
`Remove-Item -LiteralPath <파일>` 로 하나씩. 지운 목록을 보고에 적는다(내용은 적지 않는다).

### 5. 업무 요약 남기기 (사용자가 원할 때 — 서버에는 요약만)
**원본 파일은 PC 에만 둔다. 서버(SPACEKIJUN)에는 원본을 올리지 않고, 업무 수행 지식만 담은 요약을 올린다** (2026-11-05 결정).
다음에 같은 업무를 하는 사람(내년의 나·다른 선생님)이 «어떻게 했나»를 알게 하는 것이 목적이다.

1. **요약을 쓴다** — 업무 폴더에 `업무 요약.md` (아래 틀). 대화와 옮긴 파일을 바탕으로 쓰되, 파일 내용을 옮겨 적지 않는다.
   ```markdown
   # <업무명> — 업무 요약 (<YYYY-MM-DD>)
   ## 한 일 (순서)
   1. … (어느 시스템의 어느 메뉴에서 무엇을 했나 — 예: 나이스 › 학적 › … 에서 조회·입력)
   ## 쓴 자료 (종류만)
   - 원자료: 동아리별 활동 기록(엑셀) · 양식: 교육청 서식(한글) · 결과물: 입력 확인표 …
   ## 요령 · 주의
   - 놓치기 쉬운 것, 시간이 걸린 곳, 다음에 바꿀 것
   ## 참고
   - 관련 공문 제목·시행일, 메뉴 경로, 기한 (사람 이름·연락처는 쓰지 않는다 — «담당 부서»«담임»처럼)
   ```
   **넣지 않는 것:** 학생·학부모·교직원 이름(역할로 바꾼다), 학번·반·번호, 연락처·이메일·주민번호, 성적·점수·출결 같은 개인 기록,
   상담·건강·가정 사정, 파일 이름에 든 이름, PC 경로. 인원은 «학생 28명»처럼 수로만.
2. **검사한다** — 작업 중 본 사람 이름이 있으면 `-Names` 로 함께 넘긴다. 찾은 것이 있으면 고치고 다시 돌린다.
   ```powershell
   & "<스킬 폴더>\scripts\summary-check.ps1" -Path "<업무 폴더>\업무 요약.md" -Names "…"
   ```
3. **요약 전문을 보여 주고 올릴지 묻는다.** 서류함은 **모든 교직원이 본다**고 함께 알린다. 승인하지 않으면 PC 에만 둔다.
4. **올린다** (SPACEKIJUN 연결 `mcp__spacekijun__*` 이 있을 때만 — 없으면 «PC 에 요약을 남겼다»고만 알린다):
   - **서류함**: 폴더는 `list_document_folders` 에서 사용자와 고른다(예: «업무 요약»). `start_document_upload(file_name)` →
     받은 curl 명령의 `<파일 경로>` 만 요약 파일로 바꿔 실행 → `finish_document_upload(upload_path, file_name, title, folder…)`.
     제목 = `<업무명> 업무 요약 (<날짜>)`. 1회용 주소는 이 파일에만 쓴다. 자세한 규칙은 `spacekijun-mcp` 스킬 «서류함·코드 공유 파일».
   - **업무 지식** (그 일이 SPACEKIJUN 업무와 연결돼 있고 내가 책임자일 때만 — 따로 묻는다): 요령·주의 몇 줄을
     `save_work_knowledge(work_id, kind = procedure·tip·caution·reference, title, body ≤ 4000자)` 로. 다음 해 이 업무를 이어받은 에이전트가 읽는다.
   - **학교 맥락** (업무 하나에 묶이지 않는 학교의 규칙·관행·절차를 알게 됐을 때만 — 따로 묻는다): 먼저 `list_contexts` 로 같은 맥락이
     없는지 보고 `save_context(key, title, area, summary, body, contents=출처, check_only)` 로 note 를 남긴다. 미리 본 내용을 확인받은 뒤
     `check_only:false`. 모든 교직원과 에이전트가 근거를 찾을 때 본다 — 개인정보는 빼고, 확인된 사실과 출처만.
5. 올린 뒤에도 `업무 요약.md` 는 업무 폴더에 남는다(되돌리기 기록에는 들지 않는다 — 내가 만든 파일).
   서류함에서 내리려면 `delete_document`(내 문서만).

### 6. 보고
옮긴 폴더 경로·옮긴 수·건너뛴 것·지운 것·요약을 어디에 남겼나. 예: «`자동화 업무\업무\2026-10-30_동아리 누가기록 입력(8~9월)\` 로 1개 옮김, 캡처 2개 지움, 요약은 서류함 «업무 요약» 폴더에 올림».

## 되돌리기
```powershell
& "<스킬 폴더>\scripts\undo.ps1" -Folder "2026-10-30_동아리 누가기록 입력(8~9월)" -WhatIf
& "<스킬 폴더>\scripts\undo.ps1" -Folder "2026-10-30_동아리 누가기록 입력(8~9월)"
```
기록의 «옮긴 경로 → 원래 경로»로 되돌린다. 원래 자리에 같은 이름이 생겼으면 건너뛴다. 지운 파일은 되돌릴 수 없다.

## 다른 스킬과 함께
- 업무 스킬(나이스·에듀파인·쿨메신저 …)로 일을 끝낸 **마지막 단계**에서 이 스킬로 정리를 제안한다. 사용자가 원하지 않으면 건너뛴다.
- SPACEKIJUN 업무·할 일과 연결된 일이면, 보고에 폴더 경로를 적어 두면 나중에 찾기 쉽다(할 일 설명을 고치는 것은 사용자가 원할 때만).
