# 쿨메신저 쪽지 문체 프로필

- 작성일: YYYY-MM-DD
- 마지막 수정: YYYY-MM-DD
- 작성 방법: 첫 사용 인터뷰 (SKILL.md '처음 쓸 때')

> 에이전트가 쪽지 초안을 쓰기 전에 이 파일을 읽는다.
> **받는 사람 이름, 쪽지 본문, 학생·학부모 정보 같은 개인정보는 적지 않는다.** 규칙과 일반화된 예시만 적는다.

## 1. 말투
- 존댓말 수준: (예: 합쇼체 "~합니다" / 해요체 "~해요" / 둘을 섞음)
- 이모티콘·기호: (예: 문장 끝 `:)` 허용, `ㅎㅎ` 금지 / 사용 안 함)
- 문장 길이·어미: (예: 짧게 끊어서, "~부탁드립니다" 로 마무리)

## 2. 시작과 맺음
- 시작 문구: (예: `안녕하세요 :)`)
- 맺음 문구: (예: `감사합니다!`)
- 상대 호칭: (예: `○○ 선생님` 으로 부름 / 호칭 생략)

## 3. 구조
- 기본 순서: (예: 인사 → 한 줄 요지 → 상세 → 요청·기한 → 맺음)
- 형식: (예: 짧은 줄글 / 번호 목록 / 항목 분리)
- 길이: (예: 5줄 이내, 길면 항목으로)
- 제목: (예: 항상 씀 / 말머리 `[안내]` / 비워 둠)

## 4. 상대별 차이
- (예: 관리자: 결론 먼저, 존댓말 높임 / 동료: 부드럽게 / 학생·학부모: ...)

## 5. 하지 않을 것
- (예: 이모티콘 연속 사용, 느낌표 3개 이상, 개인정보 본문 포함, 긴 링크 단독 나열)

## 6. 발송 전 확인 규칙
- 기본: **모든 쪽지는 초안(받는 사람·제목·본문)을 보여 주고 승인을 받은 뒤에만 발송한다.**
- 예외: (사용자가 직접 허용한 것만 적는다. 없으면 비워 둔다. 예: 1명에게 가는 한 줄 답장은 확인 생략)

## 7. 예시 (이름·정보 없이 일반화한 문장만)
```
안녕하세요 :)
(요지 한 줄)
(상세)
(요청과 기한)
감사합니다!
```

## 8. 교정 이력 (사용자가 초안을 고쳐 달라고 할 때마다 한 줄 추가)
- YYYY-MM-DD — (무엇을 어떻게 바꾸라고 했는지 → 위 규칙에 반영했는지)
