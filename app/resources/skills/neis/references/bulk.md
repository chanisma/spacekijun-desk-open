# 부장용 일괄 작업 — 세부

모두 `inject/*.js` 를 페이지에 주입하고(`window.__NEISR/__NEIST/__NEISQ/__SA`), 순회·저장은 `tasks/bulk.js` 가 한다.

## 학생부 항목별 조회 (`records`)
- 경로: `<부서장 탭> › 학교생활기록부 › 학교생활기록부 › [학생부 항목별 조회]`(마지막은 화면 안 링크). 담임은 자기 반만.
- 학년(`계열/학년/학과`)·반 콤보 → 조회 → 왼쪽 항목 트리 → 리포트 렌더 → [저장]→[XLS Data].
- 파일명 `Grade{학년}_Class{반}_{항목}.xlsx` — 정리기(`records-merge`)가 파일명에서 학년·반을 다시 읽는다.
- 렌더 뒤 2초 기다리고 `status()` 의 학년·반이 의도와 같은지 대조(어긋나면 이전 반 리포트).
- 정리기: 반복 머리글·쪽 표시·사용자명 행 제거, 병합 셀 채우기, 같은 학생·과목 내용 잇기 → `반,학년,학기,번호,성명,과목,내용`.
  과목·내용형 항목(세특·창체·교과 등)만 정리된다. 통합 양식은 `splitBySubject` 로 과목을 다시 나누는데 일부(약 1%) 못 나누는 경우가 있다.

## 학생별 시간표 (`timetable`)
- 경로: `<부서장 탭> › 시간표관리 › 학생별시간표조회`, [수업시간표] 라디오. 반 콤보 이름은 `학급`.
- 조회 → 전체선택 → [선택출력] → 뷰어 준비 → [저장]→[XLS Data]. 학생 수 0인 반은 건너뛴다.
- 리포트 구조: 학생 1명 = 19행 블록, 7교시 × 2행(위 교실, 아래 `과목(교사)`), 열 1~7 = 월~일.
- 화면의 학생 수(`studentCount`)는 그려진 행만 센다 — 검증은 다른 자료(학적사항 번호 수)와 교차.

## 문항정보표 (`questions`)
- 경로: `<부서장 탭 또는 교과담임> › 성적 › 정기시험 › 문항정보표관리`(교과담임은 자기 과목만).
- DataSet: `dsObt`(60행 고정 — 실제 문항 수는 `dsCoranAllot` 의 정답 CSV 로), `dsSbjct`, `dmSearchText`(검증).
- 조회 전 `clearData()`, 읽은 뒤 과목·고사·학년 대조. `runChunk(고사, 학년)` 은 이미 받은 과목을 건너뛴다(재실행 안전).
- CSV: 학년도,학기,고사,학년,과목,과목명,과목코드,마감여부,과목만점,구분,문항,내용영역,난이도,배점,정답,복수정답,성취기준코드,성취기준

## 정기시험 학생답 (`answers`)
- 경로: `… › 성적 › 정기시험 › 정기시험학생답관리`.
- 목록은 DataSet 에서: 고사 `dsScrExm`, 학년 `dsScrOrdGrdDddepCdByGedIacosByExam`, 과목 `dsScrOsuCdByGedIacosNestBnByExam`, 강의실 `dsScrClrmCdByGedIacosByExamSbjt`.
- 학생별 답안은 `dmSearch.stuInvlNo/idx` 를 넣고 `subStuAnswr.send()` 를 직접 불러 `dmStuAnswr` 가 그 학생으로 바뀔 때까지 기다린다(약 0.1초/명).
- 함정: 미응답 빈 칸을 걸러내면 문항이 밀린다 / 강의실 선택이 반영 안 된 채 이전 학생이 내려올 수 있다(콤보 aria-label 과 학번 목록 둘 다 확인) / 새로고침 금지.
- 청크마다 `학생답_백업.json` 저장. 복구는 `__SA.restore(rows)`.
- 검증: `답안`·`정오` 길이 일치(0건 불일치), 한 학생이 같은 (고사·학년·과목)에서 두 강의실 = 오귀속(0건), 과목 수 = 콤보 목록 수.
  `문항별점수합` 0(서답형 총점만 입력), `지필총점` 빈칸(채점 전), 결시자 빈 답안은 정상.
- `--long`: 학생 × 문항 1행 — 문항정보표와 (고사, 학년, 과목, 문항)으로 이으면 문항 분석표.
