# 쓰기 — 동아리활동 (동아리담임)

검증: 2026-10-30 전북 고등학교, 동아리담임 탭. 실제 저장 → 다시 조회로 확인한 화면만 적는다.
화면: `동아리담임 › 학생생활 › 창의적체험활동 › 동아리활동관리` (`neis.js open 동아리활동관리 --path 동아리담임`).
스크립트: `scripts/write/` — `node scripts/write/nx.js scripts/write/<이름>.js`, 인자는 환경변수.

## 순서 (안쪽 탭)
1. **이수시간기준등록** — 활동한 날짜·교시·학년을 체크하고 저장. 여기 등록한 날짜만 누가기록 날짜 목록에 나온다.
2. **동아리활동관리 → 누가기록** — 날짜를 고르고 [일괄등록]으로 학생·이수시간·활동내용(·봉사) 저장.
3. (학기말) 학생부자료기록 — 이 문서 범위 밖.

## 공통 조작
- 부서: `[role=combobox][aria-label^="부서명"]` → `[role=option]` 글자. 누가기록 탭의 옵션은 «부서명 (교사명)» → 앞부분 일치로 고른다(`write/lib2.js selectDept`).
  1·2학년과 3학년이 **다른 부서명**일 수 있다(교육과정이 둘로 나뉜 해) → 부서마다 따로 한다.
- 확인창은 cleo 대화상자다(브라우저 dialog 아님): `write/dlg.js` 의 `read`(글·버튼) / `press('확인')`.
  저장 → «저장하시겠습니까?» [확인] → «저장이 완료되었습니다»/«저장되었습니다» [확인].
- 저장 전: 바뀐 것이 의도한 것뿐인지 DataSet 으로 본다(`neis.js data --only <ds>`). 저장 뒤: 다시 조회해서 확인한다.

## 1. 이수시간기준등록 (`write/reg.js` → `write/save.js`)
- 기간 기본값(학기초~오늘)으로 [조회]. 그리드 체크 칸: `[role=gridcell][aria-label^="N행 1학년 선택"]` (해제 상태 «선택 해제», 체크되면 «선택 선택»). 칸 안 `.cl-checkbox-field` 를 누른다.
- `DEPT=<부서> ROWS=23,24 GRADES=1,2 node scripts/write/nx.js scripts/write/reg.js` (체크만) → `neis.js data --only dsComptHr --cols allTiYmd,pir,grd01,grd02,grd03` 로 변경 확인 → `save.js`.
- DataSet `dsComptHr` 학년 칸 값: 1 = 등록, 0 = 미등록(체크 가능), 3 = 화면 «미등록» 표시(그날 그 학년 시간표 없음 등 — 체크하지 않는다).
- 행 번호 = 화면 «순번». 날짜↔순번은 `neis.js text` 로 먼저 맞춘다.

## 2. 누가기록 일괄등록 (`write/bulk.js`)
- 안쪽 탭은 `[role=link]` «동아리활동관리»(마지막 것) → «누가기록» 링크. 왼쪽 활동일자 그리드의 날짜 셀을 누르면 오른쪽에 학생 목록(학적변동사항·출결결시내역).
- [일괄등록] 창 칸: 일자(고른 날짜가 들어와 있음 — 다르면 중단), 학생 행 체크(«행 전체선택»/«N행 행선택 체크박스»), 이수시간 + «최대 이수시간 적용»(기본 켜짐 = 그날 교시 수), 정규외, 미이수 학생 대상 보충활동, 활동내용(textarea), «봉사활동실적입력» 체크, 장소 또는 주관 기관명.
- `bulk.js` env: `DEPT DAY(2026.09.18.) TEXT HOURS(비우면 최대) ONLY|EXCLUDE(학년-반-번호, 쉼표) EXPECT(학생 수) VOL=1 PLACE SAVE=1`.
  SAVE 없이 돌리면 창을 채워 상태만 보여 주고 닫는다. `SAVE=1` 이면 학생 수·문구·시간·봉사 검사를 모두 통과할 때만 저장한다.
- 이수시간 직접 입력: «최대 이수시간 적용»을 끄면 숫자칸이 0 으로 바뀐다 → **800ms 기다린 뒤 한 글자씩** 입력(안 그러면 0 이 남는다).
- 봉사: «봉사활동실적입력» 글자와 같은 줄의 체크박스 아이콘을 누른다(라벨이 체크박스 안에 없다). 켜면 장소가 «(학교)학교명»으로 **자동 입력·잠김**.
  봉사는 같은 날 **별도 기록**으로 쌓인다(동아리 1시간 기록 + 봉사 1시간 기록). 지난 봉사 예는 그 날짜 조회 뒤 `data --only dsGicRec --cols comptHr,speclActSpablMteCn,servActYn,placeMngtInstNm`.
- **결시(결과)가 찍힌 학생은 행 체크가 비활성이고 본 화면 칸도 aria-disabled** → 입력할 수 없다. «출석인정결석»이면서 결시가 같이 찍힌 경우도 막힌다 → 출결 정리는 사람(담임·동아리 출결관리)에게 넘긴다.
- 확인: `scan.js`(DEPT, DAYS) 또는 `data --only dsGicRec --cols grd,clsCd,clsNo,comptHr,speclActSpablMteCn,servActYn`.

## 3. 이미 넣은 기록 고치기 (`write/edit.js`)
- 본 화면 그리드 칸(이수시간·활동내용)을 직접 고치고 본 화면 [저장]. env: `DEPT DAY KEYS(all|학년-반-번호,…) HOURS TEXT SAVE=1`.
- 칸은 **한 번** 누르면 안쪽 textarea/input 에 포커스(두 번 누르면 풀림) → Ctrl+A·입력·Tab. **Escape 금지** — 마지막 칸 편집이 취소된다.
- 편집 직후 칸 글자는 비어 보인다 → 값은 셀 aria-label(«N행 활동내용 <값> 편집창»)에서 읽는다.

## 4. 한 학생 기록 지우기 (`write/delete.js`)
- 결시인데 누가기록이 들어가 있는 경우 등. env: `DEPT DAY KEY(학년-반-번호) SAVE=1`. SAVE 없이 돌리면 그 줄만 체크됐는지 보고 확인창(«해당 자료를 삭제하시겠습니까?»)에서 취소한다.
- 행 체크박스는 `[role=checkbox][aria-label="N행 … 행선택 체크박스"]`, 상태는 aria-checked. 결시로 잠긴 줄도 체크·삭제는 된다.

## 학교 안내에서 자주 나오는 규칙 (예: 2026 전북 고교 동아리 안내)
- 동아리 2시간 날: 학생 전체 + 최대 이수시간 + 활동내용.
- 동아리 1시간 + 봉사 1시간 날: ① 최대 해제·1시간·활동내용 ② 다시 일괄등록·1시간·봉사활동실적 체크·봉사 내용(봉사활동 계획서 문구).
- **출석인정결석 → 1·2학년만 작성**(활동내용 «활동내용 없음», 문구 그대로; 봉사 날이어도 봉사 미인정 → 동아리 2시간). 일괄등록에서 빼고(EXCLUDE) 따로 넣는다(ONLY). 3학년 출석인정결석은 작성하지 않는다(2026 담당 확인 — 학교마다 다를 수 있다).
- **결시 → 작성하지 않음**(0시간). 결시인데 누가기록이 이미 있으면 본 화면에서 그 줄만 체크해 [삭제]한다.
- 같은 날짜는 같은 활동내용. 지난 기록 문구 길이·말투에 맞춘다(짧은 명사구).
- 학교마다 다르다 — 그 학교 안내문을 먼저 읽고, 모호한 학생 처리는 담당교사에게 묻는다.
