# neis — 나이스(NEIS) 조회·안내 스킬

Claude Code(또는 Codex)에게 말로 시키면 나이스에서 다음을 해 줍니다. **모두 조회 전용**이라 저장·마감·삭제는 하지 않습니다.

- **안내(로그인 없이)**: "세특 입력은 어디서?" → 화면·경로·역할 / 화면 사용법(먼저 할 일·순서·주의·FAQ) / "왜 비어 보이지?" 규칙 / 시기별 업무
- **화면 읽기**: 인증서 로그인 → 메뉴 검색으로 화면 열기 → 일자 맞추고 조회 → 화면 글·표 읽기
- **교사용**: 과목별출결 수업일별 수집·통계(결과 `/`·출결 사유별), 일일근무상황(그날 출장·연가·외출·조퇴 건수)
- **부장용**(해당 탭 권한 필요): 학생부 항목별 일괄 XLSX + 정리, 학생별 시간표 XLSX + CSV, 문항정보표 CSV, 정기시험 학생답 CSV

## 필요한 것
- Windows 10/11, Node.js 20 이상
- 교육행정 전자서명 인증서(로컬 NPKI) + KSignCASE 인증서 프로그램
- 검증: 전북특별자치도교육청 고등학교(jbe.neis.go.kr, 2026-10). 다른 시·도는 `config.json` 의 `baseUrl` 을 `https://<시도>.neis.go.kr` 로 — 확인되지 않았습니다.
  화면 지식은 고등학교 교무업무 중심입니다.

## 설치
> ⚠ **설치 경로에 한글이 없게** 두세요(예: `C:\work\.claude\skills\neis`). 일부 Node 버전(22.11 확인)은 한글 폴더에서 스크립트를 불러오다 비정상 종료합니다.

1. 이 폴더를 스킬 폴더에 둡니다 — Claude Code: `<프로젝트>\.claude\skills\neis\`, Codex: `<프로젝트>\.agents\skills\neis\`
2. 폴더에서
   ```
   npm install
   npx playwright install chromium
   node scripts/neis.js setup            # edufine 스킬을 쓰고 있으면: setup --from-edufine
   ```
3. `%USERPROFILE%\.neis\credentials.json` 에 인증서 암호를 **직접** 적습니다(채팅에 붙여 넣지 마세요).
   ```json
   { "certPassword": "인증서 암호", "certMatch": "" }
   ```
   인증서가 여러 개면 `certMatch` 에 고를 인증서 이름 일부.
   스페이스기전 데스크를 쓰면 이 파일이 없어도 데스크 설정에 저장한 인증서 정보를 씁니다(읽기만).
4. 시험: `node scripts/neis.js find 출결` (로그인 없이) → `node scripts/neis.js session start` (브라우저가 열리고 로그인되면 성공).
   처음엔 브라우저에서 **인증서 프로그램 권한 허용**을 한 번 눌러 주세요.

## 이렇게 말해 보세요
- "학급담임이 학기말에 나이스에서 해야 할 일 순서대로 알려 줘"
- "과목별출결 마감이 안 돼. 뭘 먼저 해야 해?"
- "정보과제연구 과목 이번 달까지 출결 통계 내 줘"
- "다음 주 화요일 출장·연가 누구 있는지 건수만 알려 줘"
- "1학년 세특 전부 받아서 반별로 정리해 줘" (부장 권한)

## 개인정보
- 결과 파일(`%USERPROFILE%\.neis\out`)에 학생·교직원 이름·학번·출결 사유·병가 등이 들어 있습니다. 필요한 작업이 끝나면 지우세요.
- 스킬은 결과를 건수·통계 중심으로 보고하고, 명단은 요청할 때만 보여 줍니다. 외부 서비스로 보내지 않습니다.

## 데이터 위치 (`%USERPROFILE%\.neis`, 환경변수 `NEIS_HOME` 으로 변경)
| | |
|---|---|
| `config.json` | 나이스 주소·디버그 포트 |
| `credentials.json` | 인증서 암호(이 PC에만) |
| `out\` | 내려받은 파일·수집 결과 |
| `browser-profile\` | 인증서 권한 승인이 남는 브라우저 프로필 |

## 지식 자료의 출처
`knowledge/` 의 화면 카탈로그·사용법·규칙·업무 달력은 업무포털 「학교업무분장 메뉴목록」(2026.09)의 메뉴 구조와
「2026 상반기 나이스 교무업무 사용자 설명서(고등학교)」를 바탕으로 **요약·재구성**한 것입니다(설명서 원문은 담지 않았습니다).
나이스가 개편되면 화면 이름·순서가 달라질 수 있습니다.
