# edufine — K-에듀파인 업무 자동화 스킬

Claude Code(또는 Codex)에게 말로 시키면 K-에듀파인에서 다음을 해 줍니다.

- **공문 찾기**: 문서등록대장을 내려받아 제목·기간·생산/접수로 검색
- **공문 받기**: 본문(ODT)과 첨부를 공식 [PC저장]과 같은 권한·접근기록으로 내려받기
- **공문 기안**: 기안기(WXSClient)에 제목·본문·결재선·과제카드·공개여부·붙임을 넣고 검증 → 검토 후 결재올림
- **지출품의**: 예산 잔액 확인 → 품의 작성·저장 → 결재요청 → 기안기 마무리
- **기안 기록**: 올린 문서마다 본문·설정·상신 결과를 엑셀/메모로 남김

> 결재올림(상신)은 언제나 **사용자가 내용을 보고 승인한 뒤**에만 합니다.

## 필요한 것
- Windows 10/11, Node.js 20 이상, Windows PowerShell 5.1(기본 설치)
- 교육행정 전자서명 인증서(로컬 NPKI) + KSignCASE 인증서 프로그램
- 에듀파인 기안기(`C:\Program Files (x86)\kedu\WXSClient.exe`) — 기안·품의에 필요
- 학교회계 메뉴 권한(지출품의에 필요)
- 검증: 전북특별자치도교육청(klef.jbe.go.kr). 다른 시·도는 `config.json` 의 `baseUrl` 만 바꾸면 될 가능성이 높지만 확인되지 않았습니다.

## 설치
> ⚠ **Node 22.11·22.12 는 한글이 든 폴더의 스크립트를 불러오다 비정상 종료(Segmentation fault)** 합니다(2026-10-26 실측, 22.23.4 는 정상).
> 설치 경로에 한글이 있으면 Node.js 를 최신 LTS 로 올리거나, 한글이 없는 폴더(`C:\work\.claude\skills\edufine` 등)에 두세요. 데이터 폴더(`.edufine`)의 한글 파일 이름은 괜찮습니다.
> 스페이스기전 데스크의 `자동화 업무` 폴더에서 쓰면 데스크가 Node 를 점검해 필요하면 새 판을 깔아 줍니다.

1. 이 폴더를 스킬 폴더에 둡니다.
   - Claude Code: `<프로젝트>\.claude\skills\edufine\` 또는 `%USERPROFILE%\.claude\skills\edufine\`
   - Codex: `<프로젝트>\.agents\skills\edufine\`
2. 폴더에서:
   ```
   npm install
   npx playwright install chromium
   node scripts/edufine.js setup
   ```
3. `%USERPROFILE%\.edufine\credentials.json` 을 메모장으로 열어 **직접** 적습니다(채팅에 붙여 넣지 마세요).
   ```json
   { "id": "업무포털 아이디", "certPassword": "인증서 암호", "certMatch": "" }
   ```
   인증서가 여러 개면 `certMatch` 에 고를 인증서 이름 일부를 적습니다.
   스페이스기전 데스크(교사판) 설정에 인증서 정보를 저장해 두었다면 이 파일 없이 그것을 읽어 씁니다.
4. 시험: `node scripts/edufine.js session start` → 브라우저가 열리고 로그인되면 성공.
   처음에는 브라우저에서 **인증서 프로그램 권한 허용**을 한 번 눌러 주세요(이후에는 묻지 않습니다).

## 데이터 위치 (`%USERPROFILE%\.edufine`, 환경변수 `EDUFINE_HOME` 으로 변경)
| 폴더/파일 | 내용 |
|---|---|
| `config.json` | 포털 주소, 디버그 포트, 기안기 경로 |
| `credentials.json` | 아이디·인증서 암호 (이 PC에만) |
| `ledger\` | 문서등록대장 CSV 캐시 |
| `docs\` | 내려받은 공문 (기본 위치) |
| `logs\기안로그\` | 기안 기록 |
| `browser-profile\` | 인증서 권한 승인이 남는 브라우저 프로필 |

## 주의
- 자동화는 포털이 버튼에 걸어 둔 함수를 그대로 부르므로, 에듀파인이 개편되면 함수 이름이 바뀌어 동작하지 않을 수 있습니다. `references/` 의 함수 지도를 보고 고치면 됩니다.
- 품의를 결재요청한 뒤 되돌리기(반송·삭제)는 자동화하지 않았습니다: 업무관리 › 문서관리 › 재정문서 에서 반송 → 품의목록에서 삭제.
